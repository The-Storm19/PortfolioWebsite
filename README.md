# PortfolioWebsite

To preview website, click the green "Code" button on the main page and select 'Download .zip file".

Once the download is complete, unzip the file to the folder you want to keep it on your computer.

To open the website, go into the unzipped folder an click on "index.html".

The website should open in your default web browser. If it does not, right click 'index.html', select 'open with...' and select the browser in which yyou want to open the page
